# 主从板通信接口

---


- **总线**：CAN1（FDCAN1），1Mbps，**扩展帧**。
- **主控**：是发指令的一方，也收从板反馈。它从**蓝牙**收操作手按键，转成 CAN1 命令发给从板。
- **从板**： 对应各个机构，收到命令执行并回反馈。

**内部数据流**

```text
操作手按键(蓝牙) → 主控 按键边沿检测 → CAN1 命令 → [从板]
机构从板 反馈 → CAN1 → 主控 （→ 蓝牙状态回传）
```

> 从板**做状态机**。主控只做"按键→命令码"的映射。

---

## CAN ID 约定（基本沿用 R2 机构协议）

> 第 1,2 位=发送端，3,4 位=CAN 路(01=CAN1)，5,6 位=接收端，7,8 位=操作。设备码：1=主控，5=机构。-

| 方向        | ID 模板      |
| ----------- | ------------ |
| 主控 → 机构 | `0x010105xx` |
| 机构 → 主控 | `0x050101xx` |


---

## 命令帧（主控 → 从板）

| 操作码 | CANID        | DLC  | 数据          | 含义                      |
| ------ | ------------ | ---- | ------------- | ------------------------- |
| `0x00` | `0x01010500` | 0    | —             | 主控自检广播，从板回 `0x05010100` |
| `0x01` | `0x01010501` | 2    | `[M]`         | 使能/失能：0=失能(急停)，1=使能 |
| `0x03` | `0x01010503` | 1    | —             | left_work_1，左臂取块任务（第一次 Z=0.175+开气泵，第二次 Z=0.1） |
| `0x04` | `0x01010504` | 1    | —             | left_work_2，左臂放块任务（第一次 Z=0.525，第二次 Z=0.8） |
| `0x05` | `0x01010505` | 1    | —             | right_work_1，右臂取块任务  |
| `0x06` | `0x01010506` | 1    | —             | right_work_2，右臂放块任务  |
| `0x07` | `0x01010507` | 1    | —             | left_pulldown，左臂释放气泵（从板自定义） |
| `0x08` | `0x01010508` | 1    | —             | right_pulldown，右臂释放气泵（从板自定义） |
| `0xEE` | `0x010105EE` | 2    | `[M][错误位]` | 错误警报（待定，从板仅回确认） |
| `0xFF` | `0x010105FF` | 2    | `[R][S]`      | 复位：`R`=臂选择 0=双臂/1=左/2=右（从板自定义），`S`保留写0 |

## 反馈帧（从板 → 主控）

| 操作码       | CANID        | DLC  | 数据               | 含义                          |
| ------------ | ------------ | ---- | ------------------ | ----------------------------- |
| `0x00`       | `0x05010100` | 2    | `[状态][E/R]`      | 自检应答：`状态` 0x00=就绪/0x01=忙/0x02=电机反馈未就绪；`E/R` bit0=使能 bit1=四电机反馈就绪 |
| `0x01`       | `0x05010101` | 2    | `[M][0]`           | 使能/失能确认：`M` 0=失能，1=使能 |
| `0x03..0x08` | `0x050101xx` | 2    | `[状态][确认]`     | 对应命令的执行反馈：`状态` 0x00=已接收开始执行 / 0x01=完成 / 0x02=拒绝(忙或未使能)；`确认`=回显命令码 |
| `0xFF`       | `0x050101FF` | 2    | `[状态][确认]`     | 复位反馈（同上，`确认`=0xFF） |
| `0xEE`       | `0x050101EE` | 2    | `[错误类][设备ID]` | 错误反馈：`设备ID`=0x05(机构)  |

**握手**：主控发一条命令 → 从板回一帧确认（开始执行/完成/拒绝）。上电默认**失能**，须先发 `0x01 [1]` 使能后动作命令才被执行。

----

## Tips

1. 机构从板用 **CAN1**（`0x010105xx`/`0x050101xx`），按此 ID 基准对接。
2. 动作命令码 + 数据字段 + 反馈位表**已定稿并回填**（见上表），实现文件：
   - 解析：`IRQ/Src/CAN_IRQHandler.c` 的 `Arm_CAN_CommandParse()`
   - 命令表：`Motor/Inc/Arm_StateMachine.h` 的 `ArmCommand_t`
   - 反馈发送：`Motor/Src/Arm_StateMachine.c` 的 `Arm_FeedbackSend()`
3. 按"命令→确认"握手实现收发；状态机在从板这边。
4. **上电默认失能**：主控必须先发 `0x01 [1]` 使能，动作命令才被执行；`0x01 [0]` 失能 = 急停（电机 0 电流 + 气泵关 + 状态机复位）。
